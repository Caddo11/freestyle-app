# E-mails Freestyle

Modèles d'e-mails aux couleurs de Freestyle, en français. Supabase ne permet de les modifier
qu'une fois un serveur d'envoi (SMTP) personnalisé configuré.

## Réglages SMTP (Supabase › Authentication › Emails › SMTP Settings)
- Expéditeur : no-reply@freestyle-calisthenics.fr
- Nom de l'expéditeur : Freestyle
- Serveur, port, identifiant, mot de passe : ceux fournis par le service d'envoi (ex. Brevo :
  smtp-relay.brevo.com, port 587)

## Modèles
- confirmation-inscription.html → objet : « Confirme ton compte Freestyle »
- mot-de-passe-oublie.html → objet : « Ton nouveau mot de passe Freestyle »
- changement-email.html → objet : « Confirme ta nouvelle adresse Freestyle »
- lien-connexion.html → objet : « Ton lien de connexion Freestyle »
